# v1.1 更新说明

更新日期：2026-10-14。代码与素材继续保存在原 `v1` 目录，包版本升级为 1.1.0。

## 数据准确性

- 今日采用北京时间 00:00～次日 00:00 的半开区间，请求跨越的两个 UTC 日期，依据飞掠 Unix 时间筛选。补回前一 UTC 日期、属于北京时间凌晨的飞掠，排除次日北京时间记录。
- 完整临时编号相同的新旧条目合并，例如 `(2018 EH4)` 与 `678976 (2018 EH4)`；优先显示已编号名称和其危险分类，保留源记录 ID 与名称，不做模糊匹配。
- 增加回归用例，确保相似编号不被合并、编号天体带正式名称时仍能正确归并、缺少有效时间的条目不混入今日统计。
- 实际核验当天结果为 6 个归并后目标、3 个潜在危险。此前的 4／2 是 v1 按 UTC 日期桶及接口 ID 统计的结果，口径不同。

## 观测与科普

- 列表增加北京时间飞掠时间及已飞掠／待飞掠状态。
- 详情显示北京时间与 UTC、即将飞掠倒计时或已飞掠状态。
- 将直径标为估算直径、速度标为相对飞掠速度，并同时显示 LD 与公里距离。
- 今日统计、危险分类、飞掠时间、直径、速度、距离均有可点击说明，含 NASA/JPL 官方链接。说明弹窗支持键盘与 Escape；关闭后保留原目标详情。
- 将 JPL 天体资料与 NASA 数据说明放在详情上方，演示目标隐藏天体查询链接并标注虚构。
- 桌面／手机详情可在限定高度内滚动，保留底部控制栏；跨日刷新失败时标记为历史目标，而不是继续标为今日。

## 本地缓存

- 仅存储最近一次成功的真实 NASA 结果、查询日期和原始获取时间；演示数据不覆盖真实缓存。
- 重载先恢复同一北京时间日期的缓存，再尝试获取新数据。请求失败仍可使用缓存，明确标记“本地缓存”，不将重载时间当成数据获取时间。
- 缓存采用版本与字段白名单，不保存 API Key 或循环引用的三维对象；损坏、过期和存储权限受限时继续请求，不阻塞页面。
- 本次用临时无效配置模拟鉴权失败，实际验证跨刷新恢复 6 个目标及原获取时间；随后恢复原 Key，重新加载真实数据成功。没有保留测试配置或 Key 副本。

## 验证与范围

22 项单元测试与生产构建通过；应用内浏览器验证 1440×900 与 390×844，覆盖真实数据、去重、时区、科普、筛选联动、缓存恢复和演示倒计时。

本次未增加未来 7 天查询、服务端代理、完整历史别名解析或实际轨道传播。多个不同临时编号对应同一天体的情况仍需后续 JPL 身份映射；当前只依据确切编号合并。公开发布时的服务端 Key 管理和缓存可在下一阶段处理。
