# 产品与设计说明 · v1.1

## 目标与用户

面向天文爱好者、科普读者和展示场景。主流程为：查看今日飞掠目标 → 点击目标 → 理解直径、飞掠速度与最近距离。成功标准是用户无需理解天文学坐标即可完成该流程，并能区分真实 API 数据与演示、实际距离与示意位置。

交付包含单页网页、NASA NeoWs 接入、3D 场景、响应式交互、异常状态与文档。不包含账号、后端、碰撞预测、真实轨道传播、日期历史查询或其他行星。

## 视觉依据

视觉目标为用户选中的第 1 张，保存于 `visual-reference.png`。主色：深蓝黑 `#030712`、青 `#22D3EE`、蓝 `#3B82F6`、危险红 `#FF405C`。正文使用系统无衬线字体，数据采用系统等宽字体；图标为 Phosphor。

地球纹理采用真实公开素材，星空背景由内置 ImageGen 生成。视觉稿中随机的天文学分类文案不继承为产品数据：列表只显示本接口实际提供的「普通目标／潜在危险」。每个示意环对应一个实际目标，不增加装饰性虚构小行星。

## 信息结构

| 区域 | 信息与行为 |
| --- | --- |
| 顶栏 | 名称、北京时间查询日期、独立目标数、危险目标数、真实／缓存／演示来源、原始获取时间、刷新 |
| 观测区 | 夜光地球、大气光晕、发光目标、地心轨道环；拖拽、缩放、悬停与选择 |
| 左栏 | 距离升序目标列表、飞掠时间及状态、类别筛选、加载／失败／缓存／演示说明 |
| 右栏 | 统一名称、类别、北京时间／UTC 飞掠时刻、倒计时或已飞掠、估算直径、相对速度、LD 与公里、指标科普、NASA/JPL 来源 |
| 底栏 | 旋转、重置、颜色图例、交互提示及示意说明 |

桌面基准 1440×900；移动断点为 700px，列表通过顶部浮动按钮展开，详情为底部抽屉。列表独立滚动，详情在低屏高时滚动，不遮挡底部常驻操作。

## 状态与交互

- 初次打开：地球与 API 并行加载；成功后显示全部目标，不自动选择。
- 选择：点或列表均设置同一目标 ID，点放大、轨道加亮、行高亮、详情打开，并暂停旋转。列表使用原生按钮，支持键盘；Escape 关闭详情，恢复列表或移动端入口焦点。
- 筛选：只改变可见数据，不重新计算距离映射；筛掉当前目标时关闭详情。
- 旋转与重置：按钮显式显示当前可执行动作；重置关闭选择并恢复初始视角，减少动态效果偏好下保持暂停。
- 刷新：禁用重复请求；刷新中保留已有目标。失败保留上次数据，并说明数据日期与未更新状态。
- 数据错误：15 秒超时，展示连接、鉴权、额度或服务错误，可重试或主动进入演示；不会自动替换成演示数据。
- 无目标：保留地球，显示空状态；筛选结果为空时显示对应提示。
- 降级：WebGL 初始化失败、上下文丢失、纹理加载失败时给出说明，保留可用的数据列表和详情。
- 缓存：只保存上次成功的真实 NASA 结果；重新加载页面时先恢复同一北京时间日期的缓存，再请求新数据。缓存标签及原始获取时间保持可见，演示数据不覆盖真实缓存，API Key 和 Three.js 场景对象不入缓存。旧日期缓存不用于新日期统计；储存不可用或缓存损坏时继续请求。
- 指标科普：点击信息图标打开可键盘操作的说明弹窗，含官方解释链接；Escape 只关闭科普弹窗，保留目标详情。
- 飞掠状态：每 30 秒更新即将／已飞掠及倒计时，仅更新显示，不额外请求 API。说明环形图为距离示意，不表示真实地心轨道。

## 数据接口与可视化

查询日期通过 `Intl.DateTimeFormat` 的 `Asia/Shanghai` 时区计算。先得到北京时间 `[00:00, 次日00:00)` 的 Unix 毫秒区间，再查询所跨越的两个 UTC 日期（北京时间 2026-10-14 对应 UTC 2026-10-13 至 2026-10-14）。对整个响应按 `epoch_date_close_approach` 过滤，只保留区间内接近 Earth 的记录。起点包含、终点排除；缺少有效 epoch 的记录不计入统计，不猜测时间。

去重以完全匹配的正式编号或完整临时编号为依据，例如 `(2018 EH4)` 与 `678976 (2018 EH4)` 以同一临时编号归并，并优先显示编号名称。保留源记录 ID 与名称列表，详情说明合并条数。不能识别可靠编号的对象退回按 NeoWs ID 区分；不做相似名称或距离猜测合并。该版本未联网解析所有历史别名，因此不同临时编号但实际为同一天体的情况仍需后续 JPL 身份映射。

同一天体存在多条当日接近记录时展示最近距离最小的一条；存在已编号来源时优先使用其名称与危险分类，避免旧别名的分类覆盖当前编号记录。总体目标数与危险数均按合并后对象统计。定时器只检查日期变化，不定时轮询 API。

内部目标模型：`id`、`name`、`designation`、`hazardous`、`diameterMin/Max`（米）、`velocity`（km/s）、`distanceLD`、`distanceKm`、`approachDate`、`approachAt`（Unix 毫秒）、`jplUrl`、`sourceIds`、`sourceNames`。渲染映射增加 `radius`（地心半径倍率）及 `distanceMapped`。缺失数值为 `null`，不变成零。缓存以版本化字段白名单保存原始模型及成功获取时间，页面使用 JSON 内容前校验日期、版本、数值与来源链接。

`distanceLD` 优先读 NASA 的 `miss_distance.lunar`；缺失时按公里数除以 384,400 换算。公里字段缺失但 LD 有效时反向换算；两者均缺失则不在场景定位，详情显示「暂无数据」。

对当天有效公里距离计算 `x = log1p(distanceKm)`，令 `t = (x - min) / (max - min)`，地心半径 `r = R × (1.2 + 1.8t)`。只有一个或全部距离相同时取 `2.1R`。筛选在映射后进行。不同日期相同 LD 的示意半径可能不同，列表与侧栏原始距离用于实际比较。

方位、相位与轨道倾角来自对象 ID 的稳定散列。点与环共用半径及旋转变换；环是 Three.js 的地心闭合线，不使用 globe.gl 表面涟漪层。方向、环形轨迹和城市灯光不随真实天体历计算；相机旋转只是观测动画。

## 验收

1. API 成功时按北京时间的真实飞掠时间筛选；前一 UTC 日期的凌晨飞掠纳入，次日北京时间的飞掠除外。
2. 原始字段与单位一致，缺失显示暂无数据，危险分类只取 NASA 布尔值。
3. 半径单调、范围 1.2～3R、边界数据可用，筛选不改变已计算半径。
4. 点与列表点击联动，详情、筛选、旋转、重置、键盘及手机抽屉可操作。
5. 错误、空数据、演示和降级状态明确，演示不会冒充真实数据。
6. 桌面和手机无页面横向溢出或底栏遮挡；浏览器无相关运行时错误；单元测试及构建通过。
7. `2018 EH4` 新旧记录合并为一个对象与一个危险计数；同距不同编号不得误合并。
8. 重载后缓存仍可用、时间戳不被刷新时间伪造；请求恢复后切换真实数据；演示不覆盖缓存。
9. 科普弹窗与来源链接可操作；北京时间与 UTC 一致，公里保留 NASA 原始值，缺失时按 LD 换算。
